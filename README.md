# HAVAL — Выбор в Рязани

Самостоятельный статический сайт: 13 материалов, главная и страница об источниках.

Файлы сайта и фотографии находятся в корне репозитория. Размещается как отдельный проект Vercel: Framework Other, Root Directory ./, Output Directory ., Build Command пусто. Настройки заданы в vercel.json. Переменные окружения не требуются.

Материалы подготовлены для продвижения дилера Автоимпорт; источники и ограничения раскрыты на сайте.
